# URL Shortener (Go)

Легковесный веб-сервис для сокращения длинных ссылок, написанный на стандартной библиотеке Go (`net/http`) без использования сторонних фреймворков.

## Функционал
- Веб-интерфейс с валидацией ввода.
- Генерация уникальных 6-значных коротких ключей.
- Перенаправление (HTTP 302) по короткому адресу.
- Персистентное хранение данных в JSON-файле с автоматической загрузкой при старте.

## Запуск проекта
1. Клонируйте репозиторий и перейдите в папку проекта.
2. Запустите сервер: `go run main.go`
3. Откройте в браузере: `http://localhost:8080`
